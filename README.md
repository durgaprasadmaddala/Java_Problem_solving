Essential Logic Shortcuts & Formulas

• Reverse a Number: sum = sum * 10 + (n % 10) paired with n /= 10.
• Extract Last Digit: Use n % 10; remove it with n / 10.
• Ternary Operator: Replace simple if-else blocks with result = (cond) ? val1 : val2.
• Math Bounds: Use Math.min(a, b) and Math.max(a, b) instead of custom comparison checks.
